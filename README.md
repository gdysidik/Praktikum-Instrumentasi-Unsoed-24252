### About
This repository contains the source codes for Instrumentation Practicum at Electrical Engineering Department, Jenderal Soedirman University.

Disclaimer: This practicum was held on 2025 (2024/2025 - 2nd semester). So, in the time you access this repo, you might find the difference between your modul and mine.

### Unit 1-10
1. Unit I: Arduino Introduction
2. Unit II: Sensor Acquisition Concepts
3. Unit III: Thermal and Humidity Sensors
4. Unit IV: Sensor and Mechanical Switches
5. Unit V: Optic Sensors
6. Unit VI: Sound and Sonic Sensors
7. Unit VII: Rotational Actuators
8. Unit VIII: Display Concepts
9. Unit IX: RFID
10. Unit X: Internet of Things Introduction

### Tubes
Tugas Besar (Tubes) means the final project we made to complete the series of practicum. In this period, the Tubes built automatic conveyor sorting system based on some kind of sorting model. 
In this repo, you will find a sorting model based on color difference using LDR sensor.
